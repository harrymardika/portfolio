## Problem
Users often spend excessive time searching for relevant movies due to the abundance of choices and imprecise recommendation algorithms, resulting in decision fatigue and lower platform engagement.

## Approach
I built a recommendation system using two distinct approaches: Content-Based Filtering using Cosine Similarity to recommend movies based on genre characteristics, and Collaborative Filtering combining K-Means clustering with Deep Learning to identify patterns in user rating behavior. I cleaned and analyzed a Kaggle dataset comprising 9,742 movies and 100,836 ratings.

## Result
- Developed a Content-Based Filtering pipeline to deliver movie recommendations based on genre similarity.
- Implemented a Collaborative Filtering model using K-Means clustering and Deep Learning to personalize user recommendations.
- Processed and structured a dataset of 100,836 ratings from 610 unique users across 9,742 movies.
